# Code of conduct

- Be civil. Disagree with the code or the idea, not the person.
- No harassment, insults or personal attacks, in issues, pull requests or
  anywhere else the project is discussed.
- Assume good faith and keep reports and reviews specific and useful.

Comments that break these rules may be edited, hidden or deleted, and repeat
offenders may be blocked from the repository. To report a problem, use the
[private advisory form](https://github.com/bonkedbythonk/anicat/security/advisories/new)
or contact the maintainer through their GitHub profile.
