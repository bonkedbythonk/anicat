# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's
[private advisory form](https://github.com/bonkedbythonk/anicat/security/advisories/new)
so the report stays private until a fix is out.

Include the app version (Anicat > About Anicat), your macOS version, and the
steps to reproduce. Anicat is maintained by one person: expect a reply within
about a week, and a fix or a decision on it shortly after.

## Supported versions

Only the latest release and the latest nightly. Fixes are not backported.

## Scope

In scope: the Anicat app and its engine, including how it stores the AniList
token and talks to the sources it queries. Problems in AniList, TMDB, the
torrent sources or mpv themselves belong with their own maintainers.
